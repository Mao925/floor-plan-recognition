# Exp 2: 長期学習 (epochs=100)

## 仮説
Exp 1 (imgsz=1024) の学習曲線が50エポックで完全に平坦化していなかったため、epochs を 50→100 に増やせば、特に伸びしろのあるクラス(shower, staircase)でさらなる改善が期待できる。door, window などすでに上限近いクラスはほとんど変化しないと予想。

## 設定
- Model: YOLOv8n
- imgsz: 1024 (Exp 1 と同じ)
- epochs: **100** (Exp 1 の 50 から倍増)
- batch: 8
- patience: 25 (epochs 倍増に合わせて延長)
- seed: 42
- 学習環境: Google Colab T4 GPU

## 結果 — 仮説完全に支持

### Test セット全体
| 指標 | Baseline | Exp 1 | **Exp 2** |
|---|---|---|---|
| mAP@0.5 | 0.815 | 0.903 | **0.966** |
| mAP@0.5:0.95 | 0.616 | - | **0.734** |
| Precision | 0.823 | - | **0.959** |
| Recall | 0.733 | - | **0.936** |

### クラス別 mAP@0.5
| クラス | Baseline | Exp 1 | Exp 2 | Exp 2 で +α |
|---|---|---|---|---|
| **shower** | 0.417 | 0.730 | **0.925** | **+0.195** ⭐ |
| **staircase** | 0.704 | 0.759 | **0.907** | **+0.148** ⭐ |
| sink | 0.823 | 0.962 | 0.989 | +0.027 |
| toilet | 0.966 | 0.985 | 0.995 | +0.010 |
| door | 0.986 | 0.987 | 0.990 | +0.002 |
| window | 0.992 | 0.993 | 0.991 | -0.002 |

**全6クラスが mAP@0.5 ≥ 0.91** に到達。

### 学習時間
- 100 epochs completed in **0.248 hours (~15 分)**
- EarlyStopping せず100エポック完走
- val/mAP50 は epoch 90-100 で平坦化(0.881 → 0.882)→ これ以上 epochs を増やしても伸びは期待できない

## 興味深い観察:val と test の乖離

| | val (epoch 100) | test |
|---|---|---|
| 全体 mAP50 | 0.882 | **0.966** |
| shower mAP50 | 0.471 | **0.925** |

通常 test の方が厳しい数値になるが、本実験では逆になった。原因として val が 33 枚と少なく、shower の val 22 個 vs test 21 個でデータの偏りが大きい可能性。
**「小規模 split では val が不安定な評価指標になる」**という ML 実務上の重要な観察。

## 解釈と次の仮説
- **仮説支持**: epochs 増は「伸びしろのあるクラス」に対して効果大
- **train_loss, val_loss は最後まで微減**だが、val/mAP50 は完全に飽和 → 学習継続の追加恩恵はほぼ無い
- 副作用:学習時間 4分 → 15分(約4倍)
- **次の仮説**: 別軸の改善として、より新しいアーキテクチャ(YOLO26n)が効くか? → Exp 3 で検証
