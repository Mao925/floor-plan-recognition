# Exp 3: 最新アーキテクチャ YOLO26n との比較

## 仮説
Exp 2 と同条件(imgsz=1024, epochs=100)で、モデルを YOLOv8n → YOLO26n に切り替えると、最新アーキテクチャの恩恵で mAP@0.5 がさらに改善する可能性がある。

## 設定
- **Model: YOLO26n**(2026年1月リリースの最新版)
- imgsz: 1024 (Exp 2 と同じ)
- epochs: 100 (Exp 2 と同じ)
- batch: 8
- optimizer: auto (AdamW)
- seed: 42

## 考察 — なぜ YOLO26n が劣ったか

### 仮説1: 事前学習レシピとの不一致
公式ドキュメントによると、YOLO26 の事前学習は imgsz=640、MuSGD オプティマイザーで実施。本実験は imgsz=1024、AdamW で行ったため、事前学習の効果が活かしきれなかった可能性。一方、YOLOv8 は同じ AdamW で事前学習されているため、ファインチューニングとのギャップが小さい。

### 仮説2: NMS-free 設計と小規模データセット
YOLO26 の NMS-free アーキテクチャは end-to-end で one-to-one matching を学習する。これは大規模データセット向けの設計で、本実験の227枚という小規模データでは十分に学習できなかった可能性。

### 仮説3: モデル容量
- YOLOv8n: 130 layers, 3.0M params, 8.2 GFLOPs
- YOLO26MuSGD で再評価する価値はあるが、優先度は低い。
